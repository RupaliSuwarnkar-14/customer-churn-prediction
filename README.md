# Customer Churn Prediction

## Project Overview

This project predicts whether a customer will churn or not using Machine Learning.

## Models Used

- Logistic Regression
- Decision Tree
- Random Forest

## Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Scikit-learn
- Google Colab

## Evaluation Metrics

- Accuracy
- Precision
- Recall
- F1 Score
- Confusion Matrix

## Conclusion

This project demonstrates how Machine Learning can be used to predict customer churn.
